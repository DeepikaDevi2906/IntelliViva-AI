# 🎯 IntelliViva AI – AI-Powered Interview Evaluation System

IntelliViva AI is a Generative AI-based platform designed to simulate interview environments and provide intelligent evaluation of candidate responses. The system uses speech-to-text processing and large language models (LLMs) to analyze answers, generate structured feedback, and assign performance scores.

---

## Key Features

* **Voice-Based Input** – Users answer interview questions via speech
* **Speech-to-Text Conversion** – Converts audio responses into text
* **LLM-Based Evaluation** – Analyzes answers using AI models
* **Performance Scoring** – Provides scores based on response quality
* **Structured Feedback** – Generates detailed feedback and suggestions
* **Dashboard View** – Tracks performance across multiple attempts

## Working

1. User selects or receives an interview question
2. User responds via voice input
3. Audio is converted to text using speech recognition
4. LLM analyzes the response
5. System generates:

   * Score
   * Feedback
   * Improvement suggestions
6. Results are displayed on dashboard
